Start with a small system you can maintain. Avoid building a complicated dashboard before you understand what you need to track.

## 1. Create four areas

- **Tasks:** work that needs an action.
- **Projects:** outcomes that require several tasks.
- **Reference:** information you want to find again.
- **Archive:** completed or inactive material.

## 2. Keep the task list simple

Start with task name, status, due date and project. Add owners or priorities only if you genuinely use them.

## 3. Standardise project pages

Give each project a goal, next action, relevant links and a short progress summary. Reuse the same structure instead of reinventing it.

## 4. Review weekly

Remove stale tasks, update project status and archive finished work. A simple workspace reviewed regularly is more useful than an elaborate one that becomes outdated.

Before storing sensitive information, read current privacy, sharing and export documentation. Check current plan limits before relying on a feature for important work.
