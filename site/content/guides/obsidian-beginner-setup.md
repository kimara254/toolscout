Obsidian stores notes in a vault and uses Markdown files. Start with a structure that makes notes easy to create and retrieve.

## Start with a few folders

- `Inbox` for quick captures.
- `Projects` for active work.
- `Reference` for durable information.
- `Archive` for material you rarely need.

This is a starting point, not a rule. You can also keep a flatter folder structure and rely on links and search.

## Link related ideas

Create links when one note explains, supports or extends another. Use tags sparingly for recurring themes that are useful to filter.

## Make backups deliberate

A local vault is not automatically a backup strategy. Keep a separate backup, test that you can restore it, and understand how synchronisation works before storing sensitive information.

## Add plugins slowly

Use core features first. Add a community plugin only when you can explain the problem it solves, and review its permissions and maintenance.
